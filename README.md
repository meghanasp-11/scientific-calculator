# Calcula — Scientific Calculator

A polished, dependency-free scientific calculator based on the provided wireframe: large result area, scientific keypad, and a dedicated history panel. It can run entirely in the browser, or with the included zero-dependency Node backend for persistent history.

## Working features

- Arithmetic: +, −, ×, ÷, mod, powers, percentages
- Scientific: sin, cos, tan, sin⁻¹, cos⁻¹, tan⁻¹, log, ln, √, ∛, eˣ, |x|
- Constants: π and e
- Factorial
- DEG / RAD mode
- Parentheses + implicit multiplication (`2π`, `2(3+4)`, `2sin(30)`)
- Memory: MC, MR, M+, M−
- ANS, copy, backspace, AC
- Persistent browser history with localStorage
- Optional local backend history API using only Node built-ins
- Keyboard input and responsive layout
- No package install required

## Run the full-stack version

1. Make sure Node.js 18+ is installed.
2. From this folder run:

```bash
npm start
```

3. Open `http://localhost:5173`.

The backend serves the frontend and exposes:

- `GET /api/history` — read saved calculations
- `POST /api/history` — persist the current history array
- `DELETE /api/history` — clear saved history

History is stored locally in `data/history.json`. This is intended for a single-machine/demo deployment, not multi-user production.

## Run without a backend

You can simply open `index.html` in a modern browser. Calculations still work and history uses localStorage. The app automatically ignores the unavailable API.

## Production upgrade

For real multi-user accounts and cross-device history, replace `data/history.json` with a database such as Supabase Postgres and add authentication. Keep the calculator engine as a pure module so mathematical correctness stays independent of the UI and storage layer.

Suggested schema:

```sql
create table calculation_history (
  id bigint generated by default as identity primary key,
  user_id uuid not null,
  expression text not null,
  result text not null,
  angle_mode text not null check (angle_mode in ('DEG', 'RAD')),
  created_at timestamptz not null default now()
);
```

## What to test before judging

Try these exact expressions:

- `2+3×4` → `14`
- `(2+3)^2` → `25`
- `sin(30)` in DEG → `0.5`
- `sin(π/2)` in RAD → `1`
- `5!` → `120`
- `√(144)` → `12`
- `2π` → approximately `6.28318530718`
- `10 mod 3` → `1`
- `50%` → `0.5`

## UI rules for this version

- The calculator uses a strict two-color system only: French Wine `#AA1945` and Butter Yellow `#F5E8AA`.
- Neumorphism is created with shadows, highlights, and inset depth derived from those same two colors; no white, blue, green, purple, orange, or unrelated accent color is used.
- On desktop, the calculator is sized to the viewport so the main calculator composition does not require page-level vertical scrolling. The history list can scroll internally when it contains many entries.

## Utility key meanings

- `EXE` — execute/calculate the current expression. It performs the same calculation action as `=` and is useful when a user thinks of the key as “execute” or “enter”.
- `ANS` — insert the previous calculated answer into the current expression, so users can continue a calculation without retyping the result.
- `COPY` — copy the current result to the clipboard so it can be pasted into notes, documents, chats, or another calculation.
- `MC` — clear stored memory.
- `MR` — recall stored memory into the expression.
- `M+` — add the current value to stored memory.
- `M−` — subtract the current value from stored memory.
- `AC` — clear the current calculation.
- `⌫` — remove the last input character/token.
